常见疾病预防知识

【心脑血管疾病】

一、高血压预防
1. 控制盐摄入，每日不超过5克。
2. 保持健康体重，BMI 18.5-23.9。
3. 规律运动，每周150分钟中等强度。
4. 戒烟限酒，保持心态平和。
5. 40岁以上每年测血压。

二、冠心病预防
1. 控制血脂、血压、血糖。
2. 戒烟，避免二手烟。
3. 多吃深海鱼、坚果、蔬菜水果。
4. 规律运动，避免剧烈运动。
5. 有胸痛、胸闷症状及时就医。

三、脑卒中预防
1. 控制血压是首要任务。
2. 房颤患者需抗凝治疗。
3. 戒烟限酒，控制体重。
4. 出现口角歪斜、肢体无力、言语不清立即就医。

【代谢性疾病】

一、糖尿病预防
1. 控制体重，避免肥胖。
2. 减少精制糖、含糖饮料。
3. 多吃全谷物、蔬菜。
4. 每周150分钟运动。
5. 40岁以上每年查血糖。

二、高血脂预防
1. 减少动物脂肪、内脏。
2. 增加深海鱼、坚果、橄榄油。
3. 戒烟限酒。
4. 规律运动。
5. 40岁以上每年查血脂。

三、痛风预防
1. 减少高嘌呤食物：动物内脏、海鲜、啤酒。
2. 多喝水，每日2000ml以上。
3. 控制体重，避免肥胖。
4. 限制果糖饮料。

【肿瘤预防】

一、肺癌预防
1. 戒烟是首要任务。
2. 避免二手烟、厨房油烟。
3. 高危人群每年做低剂量CT。
4. 多吃蔬菜水果。

二、肝癌预防
1. 接种乙肝疫苗。
2. 乙肝、丙肝患者定期复查。
3. 戒酒，避免脂肪肝。
4. 避免食用霉变食物。

三、胃癌预防
1. 根除幽门螺杆菌。
2. 减少腌制、烟熏食物。
3. 多吃新鲜蔬果。
4. 40岁以上做胃镜筛查。

四、结直肠癌预防
1. 增加膳食纤维。
2. 减少红肉、加工肉。
3. 50岁以上做肠镜筛查。
4. 有家族史者提前筛查。

五、乳腺癌预防
1. 每月自检。
2. 40岁以上每年做乳腺B超。
3. 高危人群加做钼靶。
4. 保持健康体重，减少饮酒。

六、宫颈癌预防
1. 接种HPV疫苗。
2. 21岁起定期做TCT筛查。
3. 30岁起TCT+HPV联合筛查。
4. 注意性卫生。

七、前列腺癌预防
1. 50岁以上每年查PSA。
2. 有家族史者45岁起筛查。
3. 多吃番茄、豆制品。
4. 减少高脂饮食。

【呼吸系统疾病】

一、慢阻肺预防
1. 戒烟。
2. 避免粉尘、有害气体。
3. 接种流感疫苗、肺炎疫苗。
4. 注意保暖，预防感冒。

二、哮喘预防
1. 避免过敏原：花粉、尘螨、宠物毛。
2. 保持室内清洁。
3. 随身携带急救药物。
4. 定期复查。

【消化系统疾病】

一、胃病预防
1. 规律饮食，避免暴饮暴食。
2. 减少辛辣、油腻食物。
3. 根除幽门螺杆菌。
4. 戒烟限酒。

二、脂肪肝预防
1. 控制体重。
2. 减少精制糖、含糖饮料。
3. 规律运动。
4. 戒酒。

【骨骼与关节疾病】

一、骨质疏松预防
1. 增加钙摄入：牛奶、豆制品。
2. 补充维生素D：晒太阳。
3. 适量运动：负重运动、抗阻训练。
4. 50岁以上查骨密度。

二、颈椎病预防
1. 避免长时间低头。
2. 每小时起身活动。
3. 保持正确坐姿。
4. 选择合适枕头。

三、腰椎病预防
1. 避免久坐。
2. 加强核心肌群锻炼。
3. 搬重物时用腿发力，不用腰。
4. 保持健康体重。

【精神心理疾病】

一、抑郁症预防
1. 保持社交活动。
2. 规律作息、运动。
3. 学会减压。
4. 出现持续情绪低落及时就医。

二、焦虑症预防
1. 学会放松技巧：深呼吸、冥想。
2. 减少咖啡因摄入。
3. 规律运动。
4. 必要时寻求心理咨询。

【传染病预防】

一、流感预防
1. 每年接种流感疫苗。
2. 勤洗手，戴口罩。
3. 少去人群密集场所。
4. 保持室内通风。

二、乙肝预防
1. 接种乙肝疫苗。
2. 避免共用剃须刀、牙刷。
3. 注意性卫生。
4. 定期体检。

三、结核病预防
1. 接种卡介苗。
2. 保持室内通风。
3. 增强免疫力。
4. 出现咳嗽2周以上及时就医。

【综合健康建议】
1. 每年一次体检，早发现早治疗。
2. 保持健康体重，BMI 18.5-23.9。
3. 每周150分钟中等强度运动。
4. 戒烟限酒。
5. 保持良好心态。
6. 保证7-8小时睡眠。
7. 均衡饮食，多吃蔬果。
8. 定期监测血压、血糖、血脂。
