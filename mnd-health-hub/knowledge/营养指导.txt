饮食营养知识

【均衡饮食原则】
1. 食物多样：每天摄入12种以上食物，每周25种以上。
2. 谷类为主：每天摄入谷薯类250-400克，其中全谷物和杂豆50-150克。
3. 多吃蔬果：每天蔬菜300-500克，水果200-350克。
4. 适量蛋白：每天鱼禽肉蛋120-200克。
5. 少盐少油：每天盐不超过5克，油25-30克。
6. 控糖限酒：每天添加糖不超过25克，酒精不超过15克。

【各类营养素来源】

一、蛋白质
1. 优质来源：鸡蛋、牛奶、鱼、虾、瘦肉、豆制品。
2. 每日推荐：成年男性65克，女性55克。
3. 缺乏表现：免疫力下降、肌肉减少、伤口愈合慢。

二、碳水化合物
1. 优质来源：全谷物、杂豆、薯类。
2. 避免：精制糖、含糖饮料。
3. 每日推荐：占总热量的50-65%。

三、脂肪
1. 优质来源：橄榄油、深海鱼、坚果、牛油果。
2. 饱和脂肪：动物油脂、黄油，应少于总热量的10%。
3. 反式脂肪：油炸食品、烘焙食品，应尽量避免。

四、维生素
1. 维生素A：胡萝卜、南瓜、动物肝脏。缺乏导致夜盲症。
2. 维生素B族：全谷物、瘦肉、豆类。缺乏导致疲劳、口腔溃疡。
3. 维生素C：新鲜蔬果。缺乏导致免疫力下降。
4. 维生素D：阳光照射、深海鱼、蛋黄。缺乏导致骨质疏松。
5. 维生素E：坚果、植物油。抗氧化。

五、矿物质
1. 钙：牛奶、豆制品、深绿色蔬菜。缺乏导致骨质疏松。
2. 铁：红肉、动物肝脏、菠菜。缺乏导致贫血。
3. 锌：海鲜、瘦肉、坚果。缺乏导致免疫力下降。
4. 硒：海鲜、蘑菇、坚果。抗氧化。

【常见疾病饮食指导】

一、高血压
1. 控制盐摄入，每日不超过5克。
2. 多吃富含钾的食物：香蕉、土豆、菠菜。
3. 减少动物脂肪，多吃蔬菜水果。
4. 戒烟限酒。

二、糖尿病
1. 控制总热量，定时定量。
2. 选择低GI食物：全谷物、豆类、绿叶蔬菜。
3. 少吃精制糖、含糖饮料。
4. 增加膳食纤维。

三、高血脂
1. 减少动物脂肪、内脏、蛋黄。
2. 增加深海鱼、坚果、橄榄油。
3. 多吃膳食纤维：燕麦、豆类、蔬菜。
4. 戒烟限酒。

四、脂肪肝
1. 控制总热量，减轻体重。
2. 减少精制糖、含糖饮料。
3. 增加蛋白质摄入。
4. 戒酒。

五、贫血
1. 多吃红肉、动物肝脏、动物血。
2. 搭配维生素C促进铁吸收。
3. 避免浓茶、咖啡影响铁吸收。

六、骨质疏松
1. 增加钙摄入：牛奶、豆制品、小鱼小虾。
2. 补充维生素D：晒太阳、深海鱼。
3. 适量运动。

【不同年龄段饮食建议】

一、青少年
1. 保证充足蛋白质和钙，促进生长发育。
2. 多吃蔬菜水果，补充维生素。
3. 早餐要吃好，避免不吃早餐。

二、上班族
1. 规律三餐，避免暴饮暴食。
2. 减少外卖，自带午餐。
3. 多吃蔬菜水果，减少油腻。
4. 控制咖啡、奶茶摄入。

三、中老年
1. 饮食清淡，少盐少油。
2. 保证优质蛋白，防止肌肉流失。
3. 增加钙和维生素D。
4. 多吃膳食纤维，预防便秘。

四、孕妇
1. 增加叶酸、铁、钙、DHA摄入。
2. 少食多餐，避免高糖高脂。
3. 戒烟戒酒。

【饮食误区】

1. 误区：多吃水果无害。
   真相：水果含糖高，每日200-350克即可。

2. 误区：吃素更健康。
   真相：长期素食可能导致蛋白质、铁、B12缺乏。

3. 误区：喝汤最有营养。
   真相：汤中营养有限，肉才是主要营养来源。

4. 误区：吃鸡蛋升胆固醇。
   真相：每天1-2个鸡蛋对大多数人是安全的。

5. 误区：不吃晚餐能减肥。
   真相：长期不吃晚餐可能导致代谢紊乱。
